# 🧩 Sudoku Solver

A Python program that solves Sudoku puzzles automatically using Backtracking.

## 🚀 Features
- Solves any valid 9x9 Sudoku
- Uses recursion + backtracking
- Takes user input
- Displays solved board

## 🧠 Algorithm
Backtracking: tries all possibilities and backtracks when constraints fail.

## ▶️ How to Run
```bash
python sudoku.py
